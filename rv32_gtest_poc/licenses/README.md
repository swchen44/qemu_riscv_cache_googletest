# Third-party notices

GoogleTest, FFF, FreeRTOS and QEMU notices are retained here and in their original source archives. The xPack component notices are preserved byte-for-byte in xpack-components.tar.gz to avoid duplicating large NEWS/license text in Git API payloads. Inspect locally with:

    tar -xzf licenses/xpack-components.tar.gz -C licenses

The xPack binary archive also includes distro-info/licenses. The project MIT license does not replace any third-party license.
